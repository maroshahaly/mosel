# موصل — دليلك الطبي الأول

تطبيق ويب عربي (PWA) يساعد المريض على فهم أعراضه بسرية: يحدد موضع الألم على صورة جسم واقعية، ويختار أعراضه، فيحصل على الاحتمالات الأقرب مرتبة مع مستوى الاستعجال والتخصص المناسب، ولكل مرض رمز ICD-10 ومراجع طبية.

- 16 تخصصًا، و149 مرضًا، و211 عَرَضًا، والفصل تام بين أمراض الرجال والنساء.
- خريطة جسم بصور واقعية مع طبقة الأعضاء الداخلية.
- حاسبة مراحل السكري والضغط والكلى وفق ADA وACC/AHA وKDIGO.
- قسم سري للصحة الجنسية والعدوى المنقولة جنسيًا.
- يعمل دون اتصال، ولا تُرسَل أي بيانات إلى خادم.

## التشغيل
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
node tools/validate_data.mjs  # فحص البيانات
```

> ⚠️ أداة توجيه أولية وليست تشخيصًا طبيًا، ويحتاج المحتوى إلى مراجعة أطباء متخصصين قبل الاستخدام العام.
